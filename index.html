SFTP → EAM Meter Reading Automation

Automated ingestion of asset meter readings from SFTP into HxGN EAM using Apache NiFi, Groovy, JSON transformation, and REST APIs.

The flow retrieves raw meter-reading files from a secure SFTP location, validates and normalizes the content, and converts multi-record files into individual meter-reading events.

Each event is enriched with the required metadata and transformed into a structured JSON payload aligned with HxGN EAM REST API requirements.

The integration posts the payloads directly to EAM, while also providing automated archiving, logging, validation, and error routing for traceability.

The solution eliminates manual data entry, improves consistency, and provides a scalable approach for automated meter-data processing.

Tech: Apache NiFi · Databridge Pro · SFTP · Groovy · JSON · REST API · HxGN EAM

AI Corrosion Detection & Automated Maintenance

AI-powered visual inspection that analyzes pipe-flange images and automatically creates corrective EAM Work Orders when corrosion is detected.

The solution captures equipment inspection images from SFTP, extracts equipment information, validates the input, and sends the image to an AI classification API.

The AI model classifies the equipment condition as Good or Corroded and returns a confidence score.

The integration logic evaluates the AI result. Equipment identified as corroded is sent to Attune EAM through REST APIs to automatically create a Work Order.

The generated Work Order is associated with the equipment, the Corrosion problem code is populated, and the original inspection image is attached as a supporting document.

Equipment identified as Good does not trigger a corrective Work Order, demonstrating how AI-based inspection can drive condition-based maintenance decisions.

Tech: AI Vision · SFTP · Databridge Pro · REST API · Attune EAM
